# mikeweste.github.io

Personal portfolio and resume.

**Live:** https://mikeweste.github.io

## Contents

| File | Description |
|------|-------------|
| `index.html` | Portfolio (EN / RU) |
| `lqa.js` | Portfolio interactions: i18n, filters, GSAP scroll deck, hero scene |
| `lqa.css` + `lqa-fix.css` | Portfolio style sources |
| `lqa.min.css` | Built stylesheet used by `index.html` — rebuild with `python3 build-css.py` |
| `resume-game-lqa.html` | Game LQA resume (EN / RU) |
| `resume.html` | Older IT-support resume (RU, not linked from the portfolio) |
| `styles.css` | Styles for the resume pages |
| `Eremenko_Vitaliy_Resume.pdf` | Resume (PDF) |
| `assets/` | Hero and section images (WebP) |

After editing `lqa.css` or `lqa-fix.css`, run `python3 build-css.py` and bump the `?v=` query in `index.html` so browsers fetch the new files.
